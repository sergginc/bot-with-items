# RU: Бот для хранения items с описанием.
Однажды создавался как бот для хранения инструкций/рецептов для повара-пекаря пекарни.

## Перед началом работы:

1. Создайте бота Telegram через Bot-Father и скопируйте его токен.
2. Убедитесь, что **Telegram доступен в вашей стране**. В протином случае - **установите VPN** на ту машину, на которой будет работать бот.
3. Убедитесь, что на машине установлен **pyTelegramBotAPI**. Установить: `pip install pyTelegramBotAPI` в терминале.
