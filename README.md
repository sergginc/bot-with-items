# RU: Бот для хранения items с описанием.
Однажды создавался как бот для хранения инструкций/рецептов для повара-пекаря пекарни.

### Перед началом работы:

1. Создайте бота Telegram через Bot-Father и **скопируйте его токен**.
2. Убедитесь, что **Telegram доступен в стране нахождения машины**. В протвином случае - **установите VPN** на ту машину, на которой будет работать бот.
3. Убедитесь, что на машине установлен **pyTelegramBotAPI**. Установить: `pip install pyTelegramBotAPI` в терминале.
4. В файле _bot.py_, найдите строчку `TOKEN = ''`. В пустые кавычки **вставьте скопированный токен вашего бота**.

### Выдать админ-права:
Рекомендуется выдать себе админ-права в самом начале, перед глобальной работой с ботом.
После первого запуска: 
1. Пропишите в чате с ботом `/my_console_id` и загляните в консоль кода.
2. Скопипруйте набор цифр из косоли - это айди пользователя.
3. Зайдите в код, найдите функцию `def start(message):...` и раскоментируйте строчку `set_admin(-1)` и вместо `-1` впишите скопированный айди пользователя.
4. Перезапустите бота, пропишите в чате с ботом `/start`, после чего закомментируйте обратно ту строчку.

А чтобы забрать админ права нужно сделать всё то же самое, только работайте со строчкой `remove_admin(-1)`
